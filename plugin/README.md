# pming — Claude Code Plugin

AI-powered PM workspace that makes your AI assistant a real thinking partner.

## Install

```
/plugin install pming
```

## Quick Start

```
/pming:init
```

This sets up a complete PM workspace with structured context, skills, and memory.

## Skills

| Skill | What it does |
|---|---|
| `init` | Set up your PM workspace |
| `meeting-prep` | Prep for meetings with high-signal talking points |
| `stakeholder-update` | Draft audience-calibrated updates and replies |
| `decision-log` | Capture and retrieve consequential decisions |
| `prd-draft` | Generate sharp first PRD drafts |
| `prioritization` | Make hard tradeoffs with explicit reasoning |
| `11-star-experience` | Define your product ambition ladder |

## How It Works

The plugin creates a workspace of markdown files that your AI assistant reads and writes to build compounding context about your product, team, and decisions. Every interaction enriches future ones.
