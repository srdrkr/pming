# Contributing to pming

Thanks for your interest in improving pming.

We welcome contributions across docs, bug fixes, tests, and especially new community skills.

## Contributing Skills

Skills should follow the existing project pattern:

1. Create a directory under `skills/`.
2. Add a `SKILL.md` that defines the workflow, inputs, and expected outputs.
3. Keep it practical and artifact-oriented so users get reusable output.

Use an existing skill as a reference:

- [`skills/meeting-prep/SKILL.md`](skills/meeting-prep/SKILL.md)

## Roadmap Note

A community skill marketplace is on the roadmap. Until then, contributions via pull request are the best way to share skills.
